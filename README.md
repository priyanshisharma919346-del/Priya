# RAG AI Assistant

## Architecture
RAG System built using LangChain, ChromaDB, SentenceTransformers, and Groq Chat LLM.

## Setup Instructions
- Open the notebook in Google Colab.
- Load Groq API key securely using `userdata.get('Key')` or `userdata.get('key')`.

## Vector Store / Database
ChromaDB with persisted vector storage, custom chunking, and metadata filtering.
